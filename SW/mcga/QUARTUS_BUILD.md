## Next Build Fix

The MCGA framebuffer needs a Quartus-friendly memory implementation before full
compile can pass. The likely fix is to make the framebuffer read path
synchronous or move it to an explicit/inferred block RAM style that Quartus can
map instead of leaving it as registers.
