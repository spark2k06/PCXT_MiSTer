# EGA Input Status #1 Audit

This audit covers EGA-504 against `SPEC.md` sections 3.2, 9.2, and 11.5, using
`rtl/video/ega_top.v`, `rtl/video/ega_attrib_ctrl.v`, and `rtl/video/UM6845R.v`.

## Implemented Bits

`ega_top.v` now builds Input Status #1 as:

| Bit | Source | Behavior |
| --- | --- | --- |
| `0` | `ega_status_not_displaying_crtc` | Tracks horizontal/display-off or vertical blanking as generated by the EGA CRTC path. |
| `3` | `ega_status_vretrace_crtc` | Tracks the CRTC vertical retrace window. |
| `4` | `ega_status_toggle[0]` | Toggles on each selected status-read pulse. |
| `5` | `ega_status_toggle[1]` | Toggles on each selected status-read pulse. |
| Other | constant `0` | No Compaq color mux or unsupported status extensions. |

The `0x30` toggle uses a registered `ega_status_read_q` edge detector so one
guest I/O read toggles once even if `IOR` remains asserted for multiple core
clocks.

## Attribute Flip-Flop Side Effect

`ega_top.v` defines the selected status read as:

```verilog
wire ega_status_read = ega_status_cs & ~bus_ior_l;
```

The same signal feeds `ega_attrib_ctrl.status_re`. Inside
`ega_attrib_ctrl.v`, a rising `status_re` pulse resets the Attribute Controller
address/data flip-flop back to address phase.

After EGA-202, `ega_status_cs` follows Misc Output bit `0`, so both color
`3DAh` and mono `3BAh` status reads work according to the active EGA I/O range.

## Remaining Visibility Gap

The current bus-drive path still gates Input Status #1 reads with
`ega_display_sel`. That means the side effects occur for selected EGA status
reads, but the CPU-visible read value may not be driven until the EGA display
mux is active. This is intentionally left to EGA-505, which is scoped to remove
incorrect display-selection gating from register visibility.

## Deterministic Test Sequence For EGA-507

An executable status/register testbench should cover:

1. Select an Attribute Controller index, write data, then read status and prove
   the next `3C0h` write is interpreted as an index write.
2. Read the active status port four times and verify bits `5:4` alternate by
   XORing with `11b` on each read.
3. Verify bit `0` follows the CRTC not-displaying signal.
4. Verify bit `3` follows the CRTC vertical-retrace signal.
5. Toggle Misc Output bit `0`; verify the active status port moves between
   `3DAh` and `3BAh`.

## Remaining Gaps

- No executable register/status testbench can be run on this machine until a
  standalone HDL simulator is installed; see `TEST_TOOLS.md`.
- Compaq color-mux behavior for bits `5:4` is intentionally not implemented for
  the base PCXT target.
